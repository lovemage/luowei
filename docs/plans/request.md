## 🚀 核心功能模組 (四大區塊)

這四個區塊是網站的導流重心，建議採用直觀的切換機制：

### 1. 短影音與廣告服務

* **形式：** Tab 分頁切換
* **內容：**
* **分頁 A：** 短影音代操（服務流程、方案介紹）
* **分頁 B：** 廣告投放代操（投報率數據、精準受眾規劃）



### 2. 影響力變現課程

* **形式：** Tab 分頁切換
* **內容：**
* **分頁 A：** 初階課程（適合零基礎、個人品牌起步）
* **分頁 B：** 進階課程（適合商業變現、規模化營運）



### 3. AI 影響力變現課程 (重點推廣)

* **設計：** **一頁式 (Landing Page) + 差異化對比**
* **重點：** 需獨立設計強力的 CTA (呼籲行動) 區塊，並用對比圖或表格強調「AI 工具」如何提升產出效率與獨特性，區別於傳統課程。

### 4. 案例展示區

* **形式：** 雙層結構
* **第一層 (Tab 切換)：** 「短影音案例」 vs 「課程案例」
* **第二層 (Logo 牆)：** 將每個課程或學員案例以 **Logo 圖標形式** 排列。
* **交互設計：** 點擊特定 Logo 後，**跳轉至獨立分頁**（詳細介紹該案例的成功數據與心得）。

## 💡 技術執行建議

* **動態光效：** 考慮到效能，建議使用 `background-attachment: fixed` 搭配微小的 CSS Keyframes 處理頂部流照，避免過度耗損使用者的瀏覽器資源。
* **一頁式設計：** AI 課程部分建議加入 **錨點選單**，讓使用者在長網頁中能快速跳轉到重點（如：課程內容、學員反饋、價格方案）。
* **SEO 與效能：** 既然有大量的案例 Logo 點擊分頁，建議採用 **動態路由 (Dynamic Routes)** 生成分頁，並針對各個案例頁面做基礎 SEO 優化。
